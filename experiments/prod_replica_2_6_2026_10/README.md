# prod_replica_2_6_2026_10: the 2_5 production configurations on schema 2_6

Each cell is the configuration serving a 2_5 production slot, copied verbatim
(comments, seeds, cleaning, folds, window, search space, Optuna settings), with
only the dataset file changed to the 2_6 layer build. 2_6 = 2_5 + 8
`STARTER_*_BEFORE` + 17 `LU_*_BEFORE` columns (`src/nba_ou/config/dataset_versions.py`).
The question is whether those 25 columns change anything when the full tuning
recipe is rerun, unlike `lineup_signal_trial_2026_10`, which froze the 2_5
hyperparameters.

| Cells | Source (2_5, read against) |
|---|---|
| `closing_line_error`, `intermediate_line_error_t30` .. `t1080` (17) | `prod_rerun_2_5_2026_10/` (`prodrerun25_*`) |
| `closing_total_points`, `closing_spread_error` (2) | `totals_spread_2_5_2026_10/closing_*_na800.yaml` (`ts25_closing_*_na800`) |

The configs were generated by text substitution. `diff` each one against its
source (named in its header); the only changes are `experiment_name`,
`training_version`, `comparison_group`, the hypothesis preamble, the
`schema_2_6` / campaign tags, `csv_path`, `data_version` and
`expected_checksum`. The intermediate cells keep the 2_5 `_scoring` sidecar:
the 2_6 copy beside the new file is byte-identical.

## Feasibility to confirm in the preflight

2_6 adds NaN columns, and `max_na_per_row` counts them. `lineup_signal_trial_2026_10`
measured that two T-360 training games drop at budget 800. The fixed
`train_games` were set close to each horizon's ceiling (closing line_error:
6,200 against a 6,216 ceiling at budget 300), so the preflight's per-fold
training sizes must still reach every `train_games`. If a slot falls short,
lower the window in that slot only and note it here. The cell then differs from
its source by two things.

**Measured 2026-10-07 (runner preflight):** two slots fell short and were
lowered, rounding down to 25 as the sources did:

| Slot | 2_5 `train_games` | 2_6 smallest fold pool | 2_6 `train_games` |
|---|---|---|---|
| T-720 | 5,700 | 5,683 | 5,675 (-25) |
| T-840 | 5,350 | 5,329 | 5,325 (-25) |

At those two slots the cell differs from its source by about 0.5% of the
training window as well as the dataset. That is far below anything the
train-window campaigns could resolve, but it is a second difference.

## Pre-registration (written before any result)

Expected: **null at every slot.** Reasons: the frozen-hyperparameter trial was
null at closing and T-360. The new columns' rank correlation with the 2_5
residual was -0.03..+0.05. They are ~1-2% of the columns.

Reading rules:
- Pair each cell with its source on the same 610-game holdout, joined on
  date + target_line + actual outcome. The arms disagree on 25-32% of games
  from colsample reshuffling alone (lineup trial), so per-game flips are not
  evidence.
- Gate question 1 first: a difference inside either arm's seed range is no
  signal. MAE differences under ~0.05 points are a null.
- 19 cells, but intermediate horizons correlate at r ≈ 0.35 (about 2-3
  independent tests across the 16 horizons). Expect one or two cells to look
  better by luck. A real effect shows the same sign in CV and holdout across
  most horizons, not as one standout slot.
- Closing total_points / spread_error are long shots (both sources are below
  break-even). Read them only for an MAE change.
